Notes & Caveats

The engine code in the VIN (position 8) is the primary identifier on most Land Rover models from the 1990s onward. However, early vehicles (pre‑1990) may not follow this standard – they often use a different coding system or no VIN-based code at all. For those, the engine number stamped on the block is the only reliable source.

Some codes have been reused or represent multiple variants. For example, 204DTD covers 148–177 bhp versions, but the base code is identical – the exact variant is determined by the calibration and ECU, not the code. Similarly, the Rover V8 code appears across 3.5, 3.9, 4.0 and 4.6 displacements, so you need to check the engine number suffix to know the exact capacity.

If you have a Jaguar‑derived engine (AJ126, AJ133) fitted to a Land Rover, the code may be the same as in Jaguar applications. However, fitment and ECU tuning differ – always refer to the engine code decoder and cross‑check with our Fitment Matrix.

Common Mistakes When Decoding

  • Reading the wrong character in the VIN. The engine code is the 8th character on most Land Rovers. Many owners look at position 7 or 10 and get a different code.
  • Confusing the engine code with the emissions code. Some VINs include a separate emissions character – that is not the engine code.
  • Assuming all 2.0 Ingeniums are the same. 204DTD is diesel, 204PT is petrol – they are not interchangeable. The code tells you the fuel type.
  • Using the engine number suffix without the prefix. The full engine number includes a letter prefix that identifies the family – e.g., "10" for TD5. You need the full string.
  • Not verifying with a second source. Aftermarket decoders can be wrong. Always cross‑check with a known‑good reference or your dealer.

How to Verify Your Engine Code

The most reliable way to confirm your engine is to locate the engine number stamp on the block itself. This is usually found on a machined pad near the cylinder head or on the front of the block. For detailed location guides, see our Engine Number Location page.

Once you have the full engine number, use the table above to identify the base code. If the code is not listed, it may be a non‑UK market or a very early variant – consult a vetted specialist from our network.

For VIN‑based decoding, position 8 is standard on most models from the 1990s. However, Defender and Discovery 1 (pre‑1998) may use a different VIN structure – refer to the Engine Code Guide for model‑specific instructions.

Frequently Asked Questions

How do I find my Land Rover engine code from the VIN?

Look at the 8th character of the 17‑digit VIN. For example, if the 8th character is "D", it indicates a diesel engine – but you need the exact letter to decode. Use the table above to map the letter to a specific engine family.

What does the "DT" in 204DTD stand for?

"DT" typically stands for Diesel Turbo. "PT" stands for Petrol Turbo. The numbers indicate the approximate displacement (2.0L) and generation.

Is the engine code the same as the engine number?

No. The engine code is a short identifier (e.g., 306DT) that tells you the family. The engine number is a unique serial number stamped on the block, which includes the code as a prefix but also has additional digits.

What if my engine code isn't listed in the table?

If your code is not in the table, it may be a very early model (pre‑1990), a non‑UK market engine, or a rare variant. Contact a vetted specialist who can look up the exact specification using the full engine number.

Can I decode the engine code from the registration plate?

Not directly. The registration plate does not contain the engine code. You need the VIN or the engine block stamp. Our Registration Lookup Tool can sometimes pull the VIN from the plate, but you still need to decode the VIN.
