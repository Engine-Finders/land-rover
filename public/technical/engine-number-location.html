Locate the engine number on your Land Rover – whether from the VIN (8th character) or the physical stamp on the block. This guide covers all major models, from the classic Defender to the latest Ingenium-powered vehicles.

On most Land Rovers, the engine number is stamped on a machined pad on the engine block. The exact location varies by model and engine family, but we cover every common variant here. The VIN’s 8th character also encodes the engine code – use that to cross‑reference.

  • Block stamp location: typically on the left side of the block (UK passenger side) or near the front.
  • VIN position 8 gives the engine family – see our Engine Code Decoder for details.
  • Older models (pre‑1990) may use a different coding – check the block directly.

Notes & Caveats

The engine number is not the same as the VIN engine code. The engine number is a unique serial number assigned to each individual engine, while the VIN position 8 gives the engine family (e.g., 204DTD). The full engine number typically starts with the engine code prefix, followed by a serial number.

On many modern Land Rovers, the engine number is also printed on a sticker or label under the bonnet – but the block stamp is the definitive reference. Always use the stamped number for official purposes (e.g., registration, parts ordering).

Some engines (e.g., Ford‑sourced 2.2 Duratorq in Freelander 2) may have the number in a different position – always check the specific engine family guide. Our Engine Code Decoder can help you confirm which family you have.

Common Mistakes

  • Looking at the VIN and assuming that’s the engine number. The VIN contains the engine code, but the engine number is a separate serial number stamped on the block.
  • Reading the wrong side. On many Land Rovers, the number is on the left (passenger side) – but some V8s have it on the front or right side. Always check the table and workshop manual.
  • Not cleaning the area. Dirt and oil can hide the stamp. A rag and some brake cleaner may be needed to reveal the digits.
  • Confusing the cylinder head casting number with the engine number. The head often has its own casting number, not the engine serial.
  • Assuming all Ingenium engines have the stamp in the same place. While similar, the 204DTD and 204PT may have slight variations in stamp location depending on the model.

How to Verify on Your Vehicle

Once you've found the stamped number, use a flashlight and a piece of paper and pencil to take a rubbing if the digits are difficult to read. Write down the full number – it should start with a letter code (e.g., "10" for TD5, "D" for some Ingenium variants) followed by a series of digits.

Cross‑reference the prefix with our Engine Code Decoder to confirm the engine family. You can also check the 8th character of the VIN – it should match the family code you see on the stamp (e.g., if the VIN 8th is "D", the stamp should begin with a "D" or the corresponding code for that engine).

If you cannot find the stamp, or if it's worn, a Land Rover specialist can use the VIN to retrieve the original engine number from the manufacturer's database. Our network of 12 vetted JLR specialists can assist – see our Specialist Vetting page for details.

Frequently Asked Questions

Where is the engine number on a TD5?

On the TD5 engine, the number is stamped on the left side of the block (passenger side), below the cylinder head, near the fuel filter bracket. It typically starts with "10".

Is the engine number the same as the VIN engine code?

No. The VIN’s 8th character gives the engine code (e.g., 204DTD), while the engine number is a unique serial number stamped on the block. The engine number usually starts with the engine code prefix.

What do I do if the engine number is unreadable?

Try a rubbing with paper and pencil. If still unreadable, a specialist can use the VIN to look up the factory engine number, or you can use the VIN engine code as a fallback for parts identification.

Does the engine number location vary by year?

Yes. Some early models (pre‑1990) have different locations. The table above covers the most common; for older vehicles, consult the workshop manual or a specialist.

Can I find the engine number from the registration plate?

Not directly. The registration plate does not contain the engine number. You need the VIN or the block stamp. Our Registration Lookup Tool can help you retrieve the VIN from the plate.
